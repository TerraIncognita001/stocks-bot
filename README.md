# Bull & Bear Daily — бот v2

Бот щодня сам робить і публікує 4 шортси за форматом «що сталося б із твоїми $1,000». На екрані лічильник рахує гроші в реальному часі, графік росте разом із голосом, а в кінці розв'язка. Працює в GitHub Actions безкоштовно.

## Серії
| Серія | Про що | Частка |
|---|---|---|
| TIME MACHINE | $1,000 у відомій компанії 5/10/15/20 років тому, в обвал 2020 або на IPO | ~55% |
| BOUGHT THE TOP | $1,000 на самому піку (тільки якщо зараз нижче −40%) | ~15% |
| STOCK BATTLE | $1,000 у A проти $1,000 у B, дві лінії змагаються | ~30% |
| MARKET SHOCK | хто сьогодні втратив або додав найбільше $ капіталізації (будні, слот 23:00 за Лондоном) | 1 на день |

- Тікери з коментарів («do $NVDA», «nvidia please») ідуть у чергу першими.
- Бот вчиться на власних переглядах: серії та стилі гачка з кращими результатами випадають частіше.

## Файли
| Файл | Що робить |
|---|---|
| `shorts.py` | сам бот |
| `auth.py` | одноразово отримує токен YouTube (на своєму ПК) |
| `requirements.txt` | бібліотеки |
| `.github/workflows/shorts.yml` | розклад і запуск |
| `music/` | треки Pixabay; настрій за назвою (`dark`, `cinematic` → погане; `lofi`, `chill` → нейтральне; решта → добре) |
| `used.json` | пам'ять: відео, перегляди, виконані запити |
| `data/` | кеш цін і профілів (бот оновлює сам) |

## Secrets (Settings → Secrets and variables → Actions)
| Назва | Звідки |
|---|---|
| `GEMINI_API_KEY` | aistudio.google.com |
| `FINNHUB_API_KEY` | finnhub.io |
| `TIINGO_API_KEY` | tiingo.com → безкоштовна реєстрація → API Token. **Рекомендовано**: головне джерело історії цін |
| `ALPHAVANTAGE_API_KEY` | необов'язково, запасне джерело |
| `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN` | з `auth.py` |

Без Tiingo бот пробує Yahoo і Stooq, але з серверів GitHub вони працюють ненадійно.

## Розклад (час Лондона)
Відео виходять приблизно о 23:00, 00:00, 01:00 і 07:00 цілий рік (запуск о :47 попередньої години, бо GitHub стартує із запізненням). У будні о 23:00 виходить MARKET SHOCK (уже після закриття біржі в США), в інші слоти бот обирає серію сам.

## Тест без публікації
Actions → shorts → Run workflow → `dry_run` = `1` → після завершення внизу сторінки запуску **Artifacts → video** → дивишся `final.mp4`.
Там само можна примусово задати `series` (`time_machine`, `peak`, `battle`, `shock`) і `ticker` (`NVDA` або `AAPL,MSFT`).

## Налаштування без правки коду
Рядки в блоці `env:` кроку `python shorts.py`:

| Рядок | Що робить |
|---|---|
| `PRIVACY: "unlisted"` | тестові відео не публічні |
| `VOICE: "en-US-SteffanNeural"` | інший голос (за замовчуванням Andrew) |
| `RATE: "+5%"` | швидкість голосу (за замовчуванням +10%) |
| `MUSIC_VOL: "0.06"` | гучність музики (0.10) |
| `SFX: "0"` | вимкнути звукові ефекти |
| `LANGS: ""` | вимкнути переклади назв |
| `YEARS: "20"` | для TIME MACHINE завжди 20 років |
| `LEARN: "0"` | вимкнути навчання на переглядах |

## Точність
- Усі числа рахує код за цінами (скориговані на спліти й дивіденди, якщо джерело це дає). Gemini тільки формулює текст, а код перевіряє кожне число; якщо Gemini недоступний, бот бере шаблони.
- В описі пояснено, як порахували, і є застереження «Hypothetical. Not financial advice».
